# پست‌یار (PostYar)

استودیوی مینیمال تولید محتوای اینستاگرام — کپشن، هوک، هشتگ، اسکریپت ریلز و ایده کاروسل.

## اجرا

```bash
npm install
npm run dev
```

## امکانات

- تولید محتوا برای پست فید، ریلز، استوری و کاروسل
- مدیریت چند پیج با لحن و نیچ اختصاصی
- تقویم ایده هفتگی
- تاریخچه و کپی سریع خروجی‌ها
- رابط فارسی RTL با طراحی مدرن و مینیمال
